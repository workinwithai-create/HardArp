# HardArp

Four-bar hardwave arpeggio desk for bedroom producers and AI-music finishers.

Hooks need motion. HardArp writes four bars of live marimba arpeggios locked to your chords and BPM, with kit and piano. FluidR3 samples. Grid-perfect WAV + MIDI.

Distinct from TagFour, LiftTwo, ArpFour, GrooveFour, WalkFour, BassWalk.

## Pricing recommendation

One-time $19 on Gumroad (or $9 add-on inside Forge Pass $24/mo). This is a desk, not a recurring studio. Sell next to RealGrooves-style indie tools on Gumroad + a pinned X demo.
